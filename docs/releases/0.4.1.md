tensorless v0.4.1 is out!
tensorless: tuned models for the Tesla P100, in one command.

https://github.com/iammrduncan/tensorless/releases/tag/v0.4.1

Before upgrading: nothing to do by hand. Your model downloads are kept, and tensorless run pulls the new engine image (0.4.1-sm60) on its first start.

Changes:

- North-Mini-Code prompts about 40% faster => a 3,122-token prompt reads at about 600 tokens a second on one P100, up from 434 with v0.4.0's image, and a 32K prompt reads about 22% faster. On the release check's prompts the greedy text is the same as v0.4.0's, and decode stays at about 80 tokens a second.
- New engine, engine-v0.4.1 => the champion of a prefill hill climb on North-Mini-Code: faster prompt kernels for the P100, on by default, with no new setting
- Qwen3.8-27B-PN3 and Q3Floor re-measured on a P100 with the new image => unchanged: the same output, prompt speed and memory as v0.4.0's image, about 30.3 and 26.6 tokens a second
- The Inkling-2-Mini draft stays on v0.4.0's image (0.4.0-sm60), still not measured there: tensorless run shinmegamiboson/Inkling-2-Mini-LookAtMyQuant-12.8GB --allow-draft
