tensorless v0.4.0 is out!
tensorless: tuned models for the Tesla P100, in one command.

https://github.com/iammrduncan/tensorless/releases/tag/v0.4.0

Before upgrading: nothing to do by hand. Your model downloads are kept, and tensorless run pulls the new engine image (0.4.0-sm60) on its first start. The image is about 90 MB larger: it now carries Python and numpy for models that need a prepare step.

Changes:

- New model, as a draft: Inkling-2-Mini => Thinking Machines' looped mixture-of-experts model on one P100, from LookAtMyQuant's 12.8 GB pack, about 28 tokens a second in our research build. Try it with: tensorless run shinmegamiboson/Inkling-2-Mini-LookAtMyQuant-12.8GB --allow-draft
- A model can now be a pack of files => tensorless downloads and checks every file, runs the model's prepare step in the engine image, and serves it. Nothing is converted.
- New engine, engine-v0.4.0 => the Inkling model, kernels for its pack's formats on the P100, and flash attention with a relative-position bias
- North-Mini-Code, Qwen3.8-27B-PN3 and Q3Floor re-measured on a P100 with the new image: about 79, 30.5 and 26.6 tokens a second, as in v0.3.0
- The three released models keep v0.3.0's GPU wait setting (GGML_CUDA_SYNC_SCHED=auto): the engine's new default cost PN3 about 1%
